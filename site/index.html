Faithfulness checker

An AI may describe the results, but every number is checked

The checker reads a report and verifies every number, protein ID, CATH code, fold name and same-fold claim against the computed facts. It also rejects claims about biological function, because nothing here computes function. Both examples below were run through the real checker when this page was built.

Method and limits

How it works

Pipeline

  • Structures come from RCSB PDB, AlphaFold DB or CATH, cleaned to one chain of amino acids.
  • TM-align superimposes the C-alpha atoms. The TM-score runs from 0 to 1; above 0.5 usually means the same fold, and unrelated proteins score about 0.17.
  • Classification copies the fold of the most similar reference domain. The sequence baseline uses Smith-Waterman alignment with BLOSUM62.
  • Benchmarks use CATH's S40 set (no two domains share 40% identity). Confidence intervals come from 2,000 bootstrap resamples.

Limitations

    Reproduce everything

    git clone https://github.com/bafood123/proteinlens.git
cd proteinlens
make setup && make test       # pinned dependencies, offline tests
make benchmark                # main set, about 8 minutes on 4 CPUs
make benchmark-hard           # hard set, about 30 minutes
make benchmark-test           # held-out test set, about 30 minutes
make app                      # interactive app at localhost:8501
python site/build_site.py     # rebuild this page from the result files
